# 一次性脚本（历史归档）

本目录收录 2026-07-19～20 项目收尾阶段使用的**一次性**脚本。它们已完成使命，仅作为工作簿数据与代码变更的来历凭证保留，**日常不需要也不应再次运行**（重复运行可能重复写入数据行）。

| 脚本 | 当时用途 |
|------|---------|
| `启用标准回归批次.ps1` | 启用 5 个标准回归批次（现状已是启用态） |
| `补充TC45批量资产.ps1` | 写入 BATCH-TC45A/B1/B2 计划与 18 行预期断言 |
| `写入TC35输入资产.ps1` | 写入 SF0035 输入数据与 BATCH-TC35 计划 |
| `冻结TC35预期资产.ps1` | 写入 SF0035 预期汇总/明细/断言 |
| `重建调试日志预期行.ps1` | 重建 38 行 19 列预期调试日志（修正批次列错位） |
| `捕获TC35实际输出.ps1` | 捕获 SF0035 实际输出（用于与手工推导比对） |
| `捕获调试日志5套.ps1` | 捕获 SF0003/16/27/28/49 简版调试日志 |
| `补丁_运行历史20列.ps1` | 给 modRunner 接运行历史 20 列的计时/分布字段 |
| `补丁_配置错误友好化.ps1` | 给两个运行入口的 LoadConfig 包友好错误处理 |

日常使用请改用根目录下的 `运行无头验收.ps1`、`无头业务验证.ps1`、`合并预期结果.ps1` 等常驻脚本。
